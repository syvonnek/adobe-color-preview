01 — About the Event

Color correction,
reimagined for storytellers.

Adobe's new Color Mode is a breakthrough — making color correction accessible and creative for editors who've always seen it as too technical.

For decades, color correction belonged to specialists. Editors felt it was too technical, too intimidating — a world apart from the creative flow of storytelling. Adobe Color Mode changes everything.

Introduced in beta at PostProduction World, this new mode brings intuitive, powerful color grading directly into Premiere Pro — right where editors already live and work.

"Color is the ultimate storytelling tool. For the first time, editors don't need to be colorists to use it that way." — Adobe Color Mode beta user

Program Manager · Adobe Certified Expert

International Adobe trainer and educator with decades of experience in motion graphics and post-production. Eran has trained thousands of editors globally and is one of Adobe's most recognized evangelists for Premiere Pro and After Effects. He leads this event as Program Manager.
